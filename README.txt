KEERTHI CREATIONS — WEBSITE

HOW TO OPEN
1. Extract this ZIP file.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome, Edge, or Firefox.

HOW TO EDIT
- Business name and text: open index.html in VS Code.
- Colours, fonts and layout: open style.css.
- Photo gallery order: edit the image paths in index.html and script.js.
- Replace images inside the images folder (keep the filenames the same, or update the paths).
